# Theisen Reddy Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript. It showcases projects, technical stack, background, and contact information in a modern one-page style.

## Features
- Responsive landing page and navigation
- Project showcase with image carousels
- About and contact sections
- Clean, custom styling with a dark editorial theme

## Project Structure
- `index.html` — homepage
- `about.html` — background and contact info
- `projects.html` — featured projects
- `stack.html` — technologies and tools
- `styles.css` — main styling
- `script.js` — interactive behavior
- `assets/projects/` — project images and portfolio assets

## How to View Locally
1. Open the project folder in your browser, or run a simple local server from the project root.
2. If you use Python, you can run:
   ```bash
   python -m http.server 8000
   ```
3. Then open:
   ```text
   http://localhost:8000
   ```

## Notes
- This project uses no framework or build step.
- Images and content can be updated directly in the HTML and assets folders.
